# NUMI — First Memory browser export

The case study loads this player only after **Play in browser** is selected.
It is intended for desktop keyboard/controller play. Touch-only visitors are offered
the full Childhood film instead. The surrounding dialog handles fullscreen and return
to the case study. Escape exits fullscreen while keeping the game open; the footer
shows this hint only during fullscreen. Outside fullscreen, Escape remains available
to Unity. The close button returns to the case study and restores the launching
button's focus. The parent accepts the fullscreen-exit message only from this iframe
and the same origin.

`index.html`, `player.css` and `player.js` belong to the portfolio. `Build/`,
`StreamingAssets/` and `build.json` are generated by the isolated Unity export.
Do not replace this HTML with Unity's generated template.

Export recipe on this Mac:
`/Users/shanishlomov/UnityProjects/GitHub-ShenkiSh/NumiGame/BuildPlans/FirstMemoryWeb/`.
That recipe builds a separate project and preserves the full game's scenes/settings.
Media comes from Shani's original opening film and Childhood bicycle memory, with its
original soundtrack. The web copies are H.264/AAC files loaded by URL.

The build uses gzip with Unity decompression fallback, so a normal static server works
without custom compression headers. Serve over HTTP(S), not `file://`.
Keep the installed game files with this site's public assets. Vite copies them into
the deployed artifact; a fresh checkout must include them along with `build.json`.
Use the export recipe to replace them after making changes to the Unity demo.
Never deploy a manifest with `probe: true`.
